# CHRONOS demo: voiceover

`chronos-demo.mp4` runs 72 s. The voiceover is ElevenLabs **George** (warm British narrator, `eleven_multilingual_v2`). The voice was generated first, and the screen recording was then paced to it, so every action happens on its line. The captions show the same text.

| 0:12 | Example | Someone in a hurry pays exactly that. Nothing more. |
| 0:18 | Live queue | This is the café's screen. On the right, Daniel's phone. |
